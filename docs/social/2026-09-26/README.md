# Local Lens X launch pack — 26 September 2026

Four unedited screenshots from the rebuilt macOS development app, in carousel
order. They are actual UI captures, not generated mockups. The first three are
offline replays of saved runs; News is a mode preview without an answer. Replay
retains the answer and citation inspector but not every live mode-specific
panel. Do not describe these four images as a fresh four-mode benchmark or as
independently fact-checked answers.

   sqlite.org visible in the evidence pane.

   dimensions, and an exact sqlite.org passage.

   deliberately without an unverified breaking-news claim.
