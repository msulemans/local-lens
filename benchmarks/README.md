# Benchmark Workspace

No benchmark corpus or result exists yet.

This directory will contain only material that may safely be committed:

- versioned manifests;
- task IDs and prompts when licences permit;
- source and configuration hashes;
- human label schemas;
- metric versions;
- public result summaries; and
- synthetic or explicitly redistributable fixtures.

Private snapshots, model weights, paid-provider responses, protected benchmark
answers, and copyrighted corpora remain outside Git.

See `docs/EVALUATION.md` for the evaluation contract and
`docs/MODEL_POLICY.md` before proposing any model or reranker experiment.
